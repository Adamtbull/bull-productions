# Preview parity checklist

A recovered build must not replace production until all applicable checks pass.

- Home/Backlot loads.
- Existing Martial Arts Training Gym appears.
- Existing permanent prop appears.
- Existing scene layout restores.
- Set opens in Fast mode.
- Full fidelity toggle works.
- Dress/Direct switching works.
- Existing prop placement/rotation/scale works.
- Scene saves and restores from Supabase.
- Prop generation works and persists.
- Front-only Cast generation still works.
- Multiview Cast accepts Front + Left + Back (+ Right optional).
- Successful multiview Cast persists to `bp_cast` and Storage.
- Refresh/reopen preserves cast shelf entry and placement.
- No service-role/provider credentials appear in client source or network payloads.
